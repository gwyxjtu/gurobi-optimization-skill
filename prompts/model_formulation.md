# Step 3: 数学建模 (Model Formulation)

## 目标
将问题转化为标准的数学优化模型形式。

## 执行流程

### 3.1 定义集合与索引
```markdown
## 集合定义
- I = {1, ..., m}  — 产品集合
- J = {1, ..., n}  — 工厂集合
- T = {1, ..., H}  — 时间周期集合
```

### 3.2 定义参数
```markdown
## 参数定义
| 符号 | 含义 | 单位 | 来源 |
|------|------|------|------|
| d_{it} | 产品i在周期t的需求量 | 件 | data.csv |
| c_{ij} | 工厂j生产产品i的单位成本 | 元/件 | data.csv |
| K_j | 工厂j的产能 | 件/周期 | data.csv |
```

### 3.3 定义决策变量
```markdown
## 决策变量
| 变量 | 类型 | 含义 | 范围 |
|------|------|------|------|
| x_{ijt} | 连续 ≥ 0 | 工厂j在周期t生产产品i的数量 | [0, ∞) |
| y_{jt} | 二元 | 工厂j在周期t是否开工 | {0, 1} |
```

### 3.4 构建目标函数
```markdown
## 目标函数
最小化总成本：
min Z = Σ_i Σ_j Σ_t c_{ij} · x_{ijt} + Σ_j Σ_t f_j · y_{jt}
         ─────────────────────     ──────────────
         生产成本                    固定开工成本
```

### 3.5 构建约束条件
```markdown
## 约束条件
1. **需求满足** (硬约束):
   Σ_j x_{ijt} ≥ d_{it}    ∀i, ∀t

2. **产能限制** (硬约束):
   Σ_i x_{ijt} ≤ K_j · y_{jt}    ∀j, ∀t

3. **逻辑约束**:
   x_{ijt} ≤ M · y_{jt}    ∀i, ∀j, ∀t  (大M法)

4. **非负性**:
   x_{ijt} ≥ 0    ∀i, ∀j, ∀t
   y_{jt} ∈ {0, 1}    ∀j, ∀t
```

### 3.6 输出
将数学模型写入 `outputs/{问题名}/mathematical_model.md`，格式如下：

```markdown
# {问题名} 数学模型

## 模型类型
{LP/MILP/QP/...}

## 集合与索引
...

## 参数
...

## 决策变量
...

## 目标函数
min/max Z = ...

## 约束条件
1. ...
2. ...

## 模型规模
- 变量数: {N}
- 约束数: {M}
- 二元变量数: {B}
```

## 建模原则
1. **完整性**：所有物理限制都要有对应的数学约束
2. **紧凑性**：避免冗余约束，用索引集批量表达
3. **可读性**：每个变量和约束都要有清晰的中文注释
4. **一致性**：单位、量纲、索引范围必须一致
